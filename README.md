# Settings with KaKe Elements QASSA Card UI & Enhancements (LineageOS 18.1)

Customized Settings app featuring modern Android 12+ aesthetic elements backported to Android 11.

---

## Key Features

1. **Universal KaKe Elements QASSA Card UI**:
   * All sub-pages (`SettingsPreferenceFragment`, `DashboardFragment`) automatically styled into dynamic grouped cards.
   * Single items get full 18dp rounded corners (`kake_pref_card_sin`).
   * Group top items get 18dp top and 4dp bottom radii (`kake_pref_card_top`).
   * Middle items get 4dp radii (`kake_pref_card_mid`).
   * Bottom items get 4dp top and 18dp bottom radii (`kake_pref_card_bot`).
   * Dynamic Google Play Services injected tiles styled into matching cards.
   * Auto-attached chevron navigation widgets and icon frame bounds.

2. **Face Unlock Integration**:
   * Integrated face biometric enrollment and security settings controllers.

3. **VortexOS & KaKe Elements Entry**:
   * Custom dashboard categories and shortcuts for custom device settings.
